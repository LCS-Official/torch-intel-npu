# W8 权重漂移与阻尼对照

2026-10-07。本轮为 CPU 离线研究，未新增 NPU 推理调用，也未修改生产内核或公开校准器。
较强阻尼降低了权重偏移，却没有改善预先设定的整模型选择指标；继续保留原来的 1% 阻尼。
前一轮全层 W8 候选仍未通过全部质量门槛，本轮没有将其升级为默认配置。

## 权重诊断

按驱动的未舍入 `INT8 code × FP16 scale` 语义，对比原 FP16 权重。
349-token 校准的整体权重平方误差是普通 INT8 舍入的 1.8267 倍；
2,560-token 校准为 2.2868 倍，其中第 28 层 down projection 达 4.1850 倍，最差行达 11.1183 倍。
`weight-drift.json` 保留全部 210 个矩阵和旧失败案例的 30 层末 token 隐状态漂移。
这说明激活重建目标可能以更大的权重偏移换取校准误差降低，不能据此单独认定大误差的成因。

## 仅用校准轨迹选择

复用上一轮 40 条、每条 64 个 token 的 CPU FP16 轨迹。
按轨迹编号 `i % 5 == 4` 留出 8 条，其余 32 条的 2,048 行激活用于拟合。
验证使用这 8 条轨迹的原提示末位置和后续 teacher-forced 输出，共 290 个预测位置。
这里的验证是校准集内部划分，不是新的独立评测集；既有 16 条模型验证提示及 4 组续写回归未参与选择。

仅改变 GPTQ 阻尼，保留固定 FP16 行尺度、INT8 -127..127、FP64 求解、activation order、128 列块和逐行 RTN 回退。
每个矩阵的拟合投影 SSE 均不超过普通舍入；1% 研究实现与公开实现通过两个包含死列和零权重行的逐位一致检查。
预先规定按“质量失败位置数、最大相对 L2、平均相对 L2”依次排序。
质量门槛保持 logits 相对 L2 < 3%、next-token KL < 0.02。

| 阻尼 | 权重平方误差 / 普通舍入 | 平均 logits 相对 L2 | 最大相对 L2 | 质量通过 |
| --- | ---: | ---: | ---: | ---: |
| 1% | 2.3763 | 2.6418% | 14.2873% | 197/290 |
| 10% | 1.4787 | 3.1801% | 10.8467% | 171/290 |
| 30% | 1.2371 | 3.3936% | 13.4558% | 156/290 |
| 100% | 1.0942 | 3.6683% | 16.1521% | 145/290 |

以上权重误差针对内部 2,048 行拟合，不能与完整 2,560 行的 2.2868 倍混为同一份权重。
10% 阻尼改善了最差值，同时增加失败位置、恶化平均误差；按预设规则仍选 1%。
因此没有重新拟合新部署候选，也没有重复执行同方案的 NPU 回归。
下一步宜测量量化前缀带来的输入分布漂移，再验证按实际量化输入进行顺序校准，而非继续单纯加大阻尼。
