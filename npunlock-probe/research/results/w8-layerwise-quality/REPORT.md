# S47：W8逐层误差与单层FP16保护诊断

2026-10-27，Windows / Core Ultra 7 258V / NPU4000（8086:643e），驱动32.0.100.5540、编译器8.3、Torch2.14.1+cpu、Transformers5.18.0；沿用本地SmolLM2-135M-Instruct。

本轮完成30层与210个投影的误差定位，并在内部样本上比较30种整层FP16保护、7种单投影保护和原rank-32基线。内部最佳候选是代码索引24（第25层）整层FP16，但独立CPU、NPU前向和KV回归均出现通过数或token退化，**不采用该候选，不改变默认实现，也不放宽原质量门槛**。这是一轮可复现的诊断与否定性优化实验。

结论：本测例中每个投影的低秩修正均降低局部误差，剩余偏差会跨层积累；没有发现只保护一个层即可稳定消除的单点故障。末端RMSNorm仅轻微放大相对误差，输出头将误差较多投向logits的共同偏移方向。共同偏移仍计入原始L2验收。

## 固定协议与防止评测泄漏

- 复用S44原40条CPU FP16 greedy轨迹、逐行W8 GPTQ权重及rank-32残差因子；32条/2048行拟合，另8条/290位置用于本轮候选选择。W8及因子NPZ哈希均与S44完全一致。
- 内部逐层回放使用B8/S64；先验证每层及最终logits与官方HF FP16批处理路径逐位一致。B8与历史B1的Half计算可有数值差异，因此只比较本轮同批基线与候选。
- 对每个层分别计算FP16输入下的量化层输出、量化前缀输入下的FP16层输出、实际量化前缀和量化层输出。只保存标量误差，不落盘激活或logits。
- 先固定30种单层保护，再测试内部最佳层的7种单投影保护；按失败数、最大原始L2、平均原始L2、额外投影字节和标签确定唯一候选。选定后才构造本轮独立评测集，未用独立数据换层、换投影或修改策略。
- 原17例/142位置与S45的16例/128位置都是已有独立历史集合，不能称作新盲测。使用FP16教师轨迹和原有token位置；前向与KV两种执行路线分别报告。
- 每位置门槛始终为 **raw logits relative L2 < 0.03 且 KL(reference || actual) < 0.02**；去均值误差、偏移能量和argmax只作附加诊断。

## 复现

需要已构建的本地运行环境、requirements-models.txt和已有SmolLM2-135M-Instruct。按顺序运行，所有NPU命令串行执行；无须新增pip包或重建DLL/PYD/ELF。prepare会拒绝覆盖已有权重，清理过原始结果后需重新准备。

```powershell
$env:PYTHONUTF8="1"
$env:PYTHONDONTWRITEBYTECODE="1"
python -B -m unittest test_torch_npu_w8_layerwise
.\run_torch_npu.ps1 -Script npunlock-probe\research\w8_layerwise_quality.py -ScriptArguments @("prepare")
.\run_torch_npu.ps1 -Script npunlock-probe\research\w8_layerwise_quality.py -ScriptArguments @("internal")
.\run_torch_npu.ps1 -Script npunlock-probe\research\w8_layerwise_quality.py -ScriptArguments @("independent")
foreach ($variant in @("corrected","selected","fp16")) {
  .\run_torch_npu.ps1 -Script npunlock-probe\research\w8_layerwise_quality.py -ScriptArguments @("hardware","--variant",$variant)
}
foreach ($variant in @("corrected","selected")) {
  .\run_torch_npu.ps1 -Script npunlock-probe\research\w8_layerwise_quality.py -ScriptArguments @("hardware-kv","--variant",$variant)
}
```
